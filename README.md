# 그리움 (Geurium)

주간보호센터 어르신이 만든 작품을 남겨 **가족에게 닿게 하는** 서비스입니다.
작품은 매일 만들어지는데 며칠 뒤면 버려지고, 가족은 그런 게 있었는지도 모릅니다. 그 사이를 잇습니다.

## 여기 무엇이 있나

| | 무엇 | 열기 |
|---|---|---|
| **설문 · 이야기 흐름** | 서비스를 5장면으로 설명하고 의견을 받습니다 | `index.html` |
| **스토리보드** | 현장(어르신·직원)과 가족 관점을 각각 걸어볼 수 있습니다 | `story.html` |
| **실제 앱** | 사진 올리기 → 이름칸 잘라내기 → 저장. **사진 없이 견본으로도** 해볼 수 있습니다 | `app/index.html` |
| 가족 열람 화면 | 링크 하나로 쌓인 작품을 봅니다 — **지금은 잠겨 있습니다**(아래) | `app/view.html` |

## 만져보실 때

- **로그인 없이 쓰면 사진은 「이 기기 안에만」** 저장됩니다. 어디로도 전송되지 않습니다.
- 사진이 없어도 **「견본으로 해보기」**로 끝까지 볼 수 있습니다.
- 로그인은 센터 직원용입니다. 계정은 센터가 만들어 줍니다(셀프 가입 없음).

## ⚠️ 가족 공유 링크는 지금 잠겨 있습니다

가족에게 보내는 링크 발급을 **일시적으로 멈춰두었습니다.**
링크 없이도 사진이 열릴 수 있는 문제를 확인해, **안전하게 고치는 동안** 닫아둡니다.
올리기와 저장은 그대로 동작합니다.

## 담기지 않는 것

이 저장소는 **공개**입니다. 그래서 여기엔 다음이 들어가지 않습니다.

- 실제 어르신의 사진·이름·연락처 등 개인 데이터
- 비밀 키 (공개해도 되는 값만 씁니다. 실제 접근 통제는 서버 쪽 권한 규칙이 합니다)
- 데이터베이스 설계·정책 파일

커밋마다 자동 검사기가 비밀·개인정보가 섞였는지 확인합니다.

## 설계에서 지킨 것

- **작품만 담고 얼굴은 담지 않습니다** — 초상권 문제를 설계로 비켜갑니다.
- **이름은 정해진 칸에만 쓰고, 저장할 때 그 칸을 잘라냅니다** — 실명이 사진에 남지 않습니다.
- **지우는 것은 확인 뒤에** 합니다 — 먼저 지우면 잘못 짝지은 것을 고칠 근거가 사라집니다.
